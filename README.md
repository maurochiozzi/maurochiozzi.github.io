# Mauro Chiozzi - Portfolio

An awesome web application to show my projects to the world :D

This application was born from the necessity to have an accessible and easy-to-use web-based application so projects could be centralized and easily shared with interested parties. It is a React application deployed on GitHub using GitHub Pages.

## Tech Stack

- **React**
- **Styled Components**
- **Material UI**
- **GitHub Pages**

## Disclaimer

The project source is open, but since it contains personal data and specific structures, it is not recommended to clone it for direct reuse. It serves best as a reference or for consultation.

## Available Scripts

In the project directory, you can run:

### `yarn start`

Runs the app in the development mode. Open http://localhost:3000 to view it in the browser.

### `yarn test`

Launches the test runner in the interactive watch mode.

### `yarn build`

Builds the app for production to the `build` folder.

### `npm run format`

Formats the entire codebase using Prettier.

### `npm run lint`

Runs the linter (ESLint) to catch code quality issues.

### `npm run analyze`

Builds the project and opens a visualization of the bundle size to help with performance optimization.

### `npm run clean`

Deletes `node_modules` and the `build` folder. Useful for resetting the environment.

> **Note:** This project uses **Husky** and **lint-staged** to automatically format and lint your code before every commit.

## CI/CD

This project uses **GitHub Actions** to automatically build and deploy the application to GitHub Pages whenever changes are pushed to the `main` or `master` branch.
